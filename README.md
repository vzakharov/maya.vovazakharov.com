# maya.vovazakharov.com

This repository holds no source. Its `gh-pages` branch is one commit — the built
static export of [maya.vovazakharov.com](https://maya.vovazakharov.com) —
force-pushed from
[vzakharov/vovazakharov.com](https://github.com/vzakharov/vovazakharov.com) by
`scripts/publish-site.sh`. GitHub Pages here is set to deploy from that branch,
so the push *is* the deploy and nothing runs over here.

The site's pages, the code that renders them and the deploy workflow all live in
the source repository. Open an issue there.
